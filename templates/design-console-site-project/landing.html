Workflow

从一句话到上线，四步

每一步都留痕：需求、设计系统、快照与验收结果都能回看，交接给同事时不用再复述一遍上下文。

  1. 1

    描述需求

    用一段话说明业务、受众与调性。可以直接引用一套已有的设计系统作为约束。

  2. 2

    生成设计系统与页面

    先产出色彩、字体、间距与组件规范，再据此生成页面，同时写入第一版快照。

  3. 3

    评审并迭代

    对比视觉 Diff 定位变化，收集团队评论，逐条改完再存一版新快照。

  4. 4

    通过门禁并交付

    质量门禁全绿后导出多语言版本，拿到可部署的产物与完整的交付记录。

Quickstart

三步拿到第一个版本

不装 CLI，不配构建。模型信息填一次，之后都在工作台里点。

localhost:8787
# 1. 创建工作台并启动
$ npx design-console start

# 2. 填入模型信息（也可在设置页里改）
$ export DC_MODEL="deepseek-chat"
$ export DC_API_KEY="sk-..."

# 3. 打开浏览器，新建项目，说一句话
#    「为一家新中式茶馆做一个落地页，安静克制」
#    → 设计系统 → 落地页 → 快照 v1 → 门禁报告

开始前需要

  • Node.js 22.5 或更高版本
  • 一个模型服务商的 API Key
  • 现代浏览器（Chrome / Edge / Safari / Firefox）

拿到第一个版本之后

  • 直接部署产物，或导出多语言版本
  • 把只读链接发给同事收集评论
  • 在用量页核对本次生成的消耗
