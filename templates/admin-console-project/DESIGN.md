# 深流 Deepflow 控制台 · 通用后台管理系统
> Category: custom
> Direction: Dark Tech（深色科技）

## 1. Visual Theme & Atmosphere

面向企业内部使用的通用后台管理系统。整体基调是"生产环境控制台"：极深的海军蓝黑底（#0B0F1A 系）配合高信息密度布局，深色侧边导航承载功能入口，玻璃质感卡片承载核心指标。数据即装饰——用真实的数值、环比箭头、状态点填充留白，不做插画和 emoji。信息层级清晰：左侧导航 → 顶部工具条 → 统计卡片 → 数据表格，一眼可定位操作入口。

三条氛围规则：
1. **侧边导航是主入口**——仪表盘、用户管理、订单管理、数据分析、系统设置按业务频次排序，当前项高亮。
2. **统计卡片讲对比**——每张卡带环比涨跌箭头与补充口径（近7天新增、退款率、客单价），数据可追溯。
3. **表格承载长列表**——用户列表带筛选 tabs、状态徽标（活跃/待验证/已停用）与分页，支持批量操作入口。

## 2. Color Tokens

### 背景层
- `--bg-deep: #0B0F1A`（页面最底、侧边导航）
- `--bg-base: #0F172A`（主背景）
- `--bg-elevated: #111C33`（抬升面：统计卡片、表格行）
- `--bg-glass: rgba(255,255,255,0.045)`（玻璃卡片面）
- `--bg-glass-strong: rgba(255,255,255,0.07)`（悬停/选中态玻璃面）

### 描边层
- `--stroke-glass: rgba(255,255,255,0.10)`（卡片默认微光描边）
- `--stroke-strong: rgba(255,255,255,0.18)`（悬停描边、分隔强调）

### 强调色
- `--primary: #4C8DFF`（主蓝，导航高亮、主按钮）
- `--success: #22C55E`（活跃状态徽标）
- `--warning: #F59E0B`（待验证状态徽标）
- `--danger: #EF4444`（已停用状态徽标、环比下跌箭头）
- `--gradient-cta: linear-gradient(120deg, #2F6BE0 0%, #4C8DFF 100%)`（实心按钮底色）

### 文字层
- `--text-primary: #EDF1FB`（标题、关键数字）
- `--text-secondary: #A9B6D4`（正文）
- `--text-muted: #7C89AC`（辅助说明、标签，对比度 5.5:1）
- `--text-on-accent: #FFFFFF`（按钮上的文字）

## 3. Typography

- 标题：系统无衬线 600（统计卡数值 28px、面板标题 15px）
- 正文：系统无衬线 400（13px）
- 辅助：系统无衬线 400（11-12px，时间戳、说明文案）
- 数据：等宽字体用于 UID、调用量数值（1.36M / 2.00M）

## 4. Spacing & Layout

- 侧边导航固定 208px，主区自适应
- 容器间距 8 的倍数（8/16/24/32px）
- 统计卡片四宫格 1fr 布局，表格行高 56px

## 5. Components

- 侧边导航：品牌区 + 功能入口列表 + 底部系统状态（调用量进度条、版本号）
- 顶部工具条：全局搜索（Ctrl K）、通知、管理员账号
- 统计卡片：指标名 + 大数值 + 环比箭头 + 补充口径
- 数据表格：列标题 + 状态徽标 + 查看/编辑行操作 + 分页控件
- 筛选 tabs：全部 / 活跃 / 待验证

## 6. Imagery

（无外部图片依赖，纯 CSS/矢量构建）

## 7. Tone of Voice

- 中文界面，克制专业：生产环境·数据每 5 分钟同步
- 状态用徽标动词：活跃 / 待验证 / 已停用
- 操作动词短：查看、编辑、导出报表、邀请用户

## 8. Anti-Patterns

- 禁止无对比度的浅色文字
- 禁止统计卡片无口径的裸数字（必须带环比或补充说明）
- 禁止导航入口无高亮态

## 9. Accessibility

- 正文对比度 ≥ 4.5:1
- 状态不只靠颜色区分，配合文字徽标（活跃/待验证/已停用）
- 交互目标（查看/编辑/分页）点击区 ≥ 28px
