## 0. 与蓝本的关系（两处改动：暖色板 + 题材）

## 1. Visual Theme & Atmosphere

画布是带橄榄暖调的近黑（`#101008`），像凌晨四点的烘焙间：只有一盏灯，灯光是琥珀色。顶部一条中亮度带（`#241d14`）承载页头与 Hero，往下沉到 `#101008` 的深色区，最后收进页脚——明度自上而下递减，和参考稿一致。

科技感不来自发光和渐变，而来自三件事：**等宽字排版的结构信息**（粉量、水温、粉水比、时长）、**配方卡式的内嵌面板**、以及**唯一的琥珀色只出现在交互与强调的位置**。页面读起来应该像一张写得很好的冲煮配方卡，而不是一张咖啡海报。

**Key Characteristics:**
- 三段明度：中亮度带 `#241d14` → 深色区 `#101008` → 页脚 `#101008`；卡片抬升到 `#1b1811`
- 头发丝分隔线 `#33302a`：只在组件内部与区块边界出现，不做装饰
- 系统无衬线 400–600，权重上限 600，层级靠字号与颜色而非字重
- 衬线（Display 栈）只出现在 Hero 大标题与收尾标题
- 等宽字承担标签、配方参数、度量与状态——科技感的唯一来源
- 琥珀 `#D4945A` 是系统里唯一的彩色，只用于链接、图标、圆点、等宽关键字与主按钮底色
- 配方卡用两层底色（`#1b1811` 外框内嵌 `#101008`），高亮行用 `#d09058` 底 + `#101008` 字
- 无渐变、无发光、无投影、无 emoji；层级一律由表面明度与分隔线承担

## 2. Color Palette & Roles

### Surface（表面层级，自上而下三段）
- **Band**（`#241d14`）：页头与 Hero 的中亮度带，对 `#101008` 对比度 1.15:1（可辨的区块边界，不是阴影）。
- **Canvas**（`#101008`）：特色区与页脚背景、配方卡内嵌面。
- **Elevated**（`#1b1811`）：卡片、配方卡外框、到店条带。
- **Divider**（`#33302a`）：组件内分隔线、页头底边、页脚顶边、卡片 hover 描边。
- **Line strong**（`#807878`）：次级按钮描边、状态圆点、装饰几何。**对比度 3.9:1（对 Band）／4.4:1（对 Canvas），只用于非文字几何。**

### Text（文字层级，实测对比度对 Canvas / Band / Elevated）
- **Text 1**（`#f0e8e0`）：15.7:1 / 13.7:1 / 14.6:1。展示标题、区块标题、卡片标题、按钮文字。
- **Text 2**（`#c4bcb2`）：10.2:1 / 8.9:1 / 9.4:1。正文、卡片描述、等宽取值。
- **Text 3**（`#9c9489`）：6.4:1 / 5.6:1 / 5.9:1。元信息、说明、页脚链接、等宽标签。
- **Text 4**（`#807878`）：4.4:1，**禁止承载任何文字**，只做描边与圆点。

### Accent（唯一彩色）
- **Amber**（`#D4945A`）：对 Canvas 7.4:1。链接、图标、勾选标记、状态圆点、等宽结构关键字、主按钮底色（配 `#101008` 字，7.4:1）。
- **Amber Deep**（`#d09058`）：高亮行底色（配 `#101008` 字，7.1:1）、主按钮 hover／按下态。
- **Stamp**（`#f0e8e0` 底 + `#101008` 字，15.7:1）：全页只出现一次的浅底 chip。

## 3. Typography

### Font Family
- **Display / Editorial**: `Signifier`, fallback `'Source Serif Pro', Georgia, 'Songti SC', 'Noto Serif SC', serif`

- **Code / Mono**: `Söhne Mono`, fallback `ui-monospace, 'JetBrains Mono', Menlo, Consolas, monospace`

### Principles
- **字重上限 600**。层级来自字号与颜色，不来自加粗。
- **衬线给灵魂，无衬线给系统**：Display 栈只出现在两级展示标题。
- **等宽字是科技信号的载体**：粉量、水温、粉水比、时长、状态。
- 展示级负字距 -0.02em；到 16px 归零。

### 配方卡着色规则（只用白名单内的颜色）
- 结构关键字（`from` / `import` / 参数名）→ `#D4945A`
- 字符串与取值 → `#c4bcb2`
- 注释与产区说明 → `#9c9489`
- 其余 → `#f0e8e0`
- 高亮行（唯一一处强调）→ 底 `#d09058`，字 `#101008`

## 4. Spacing & Layout

- **Base unit**: 4px。刻度 4, 8, 12, 16, 24, 32, 48, 64, 96, 128。
- **Container**: max-width 1200px，桌面 48px、移动 24px 边距。
- **Section rhythm**: 桌面区块间 96–128px，移动 64px。
- **Grid**: 卡片栅格 2 列（特色卡片）/ 3 列（参数列表），间距 24px。
- **三段明度**：Band `#241d14`（页头 + Hero）→ Canvas `#101008`（特色区 + 页脚）→ Elevated `#1b1811`（卡片、到店条带）。**分层而非阴影**。

## 5. Components

### Buttons
**Primary** — 底 `#D4945A`，字 `#101008`，padding 10px 18px，圆角 12px，hover／按下底 `#d09058`。
**Secondary** — 底透明，字 `#f0e8e0`，描边 1px `#807878`，padding 10px 18px，圆角 12px，hover 底 `#1b1811`、描边 `#9c9489`。
**Quiet** — 透明底，字 `#9c9489`，hover 字 `#f0e8e0`、底 `#1b1811`。
**Focus** — `outline: 2px solid #D4945A; outline-offset: 2px`，对所有可交互元素生效（深色下不再叠加蓝本的 12% 光晕，避免发光）。

### Cards
底 `#1b1811`，无描边，圆角 16px，padding 32px。`border:1px solid transparent` 预留位置，hover 转为 `#33302a`，避免布局跳动。深色下不使用投影表达层级。
**强调卡**：描边常驻 1px `#D4945A`，hover 保持不换色——用一条 1px 边而非大面积色块表达「本季主推」。全页只出现一张。

### Recipe panel（配方卡，蓝本 Console 的翻译）
外框 `#1b1811`；头部与脚部各配 1px `#33302a` 分隔线；主体 `#101008`；圆角 16px。头部左侧为等宽文件名，右侧为方法标签 chip（透明底 + `#33302a` 描边 + `#c4bcb2` 字）。

### Pills, Tags & Spec rows
**Tag**：透明底，描边 1px `#33302a`，字 `#c4bcb2`，padding 4px 10px，圆角 9999px，字号 12/500 等宽。
**Stamp**：底 `#f0e8e0`，字 `#101008`，全页只用一次。
**Spec row**：等宽 13px，两列 `88px 1fr`，键 `#9c9489`、值 `#c4bcb2`，行距 8px，块上方压 1px `#33302a` 分隔线。

### Inputs
深色下不存在真实表单控件；需要时：底 `#101008`，描边 `#33302a`，focus 描边 `#D4945A`。

## 6. Imagery

- **不使用位图**：没有照片、插画与纹理，全部信息由字体、几何与留白承担。
- **品牌标记**：24×24 圆角 8px 的琥珀方块（`#D4945A`），内嵌 `#101008` 的滤杯线稿（SVG，1.2px 描边）。
- **勾选标记**：20×20 SVG，1.5px `currentColor` 描边，颜色继承 `#D4945A`。
- **状态圆点**：8px 实心 `#D4945A`，只出现在配方卡脚部与页脚状态行。

## 7. Tone of Voice

- **写参数，不写形容词**：「92 °C / 1:15 / 2:30」优于「精心萃取」。
- **给可核验的事实**：到店天数、每日杯数、开始时间、取消规则。
- **第二人称、短句、句号收尾**；不用感叹号，不用「臻选」「匠心」「唤醒味蕾」这类空词。
- **中文为主，英文只出现在等宽标签与产区名**（产区、处理法保留原文拼写）。
- **CTA 用动词短语**：「预约品鉴」「查看豆单」「点一杯」「预订这支豆」。

## 8. Anti-Patterns

- 禁止渐变（含 `linear-gradient` / `radial-gradient` 做的网格、光晕、遮罩）。
- 禁止 token 之外的任何颜色；禁止用琥珀大面积铺底（只做按钮、链接、图标、圆点与高亮行）。
- 禁止 700 及以上字重。
- 禁止 emoji 装饰、彩色圆点、发光与投影。
- 禁止 `<table>` 布局。
- 禁止把 `#807878` 用在文字上（4.4:1，未达 4.5:1）。
- 禁止循环动画、打字机效果与滚动劫持。
- 禁止把同一套字号字重铺满全页，层级必须可见。
- 禁止咖啡题材的常见俗套：拿铁拉花照片、棕色渐变底、纸纹与手写体。

## 9. Accessibility

- 正文与元信息对比度 ≥ 4.5:1（实际最低 5.6:1，见 §2 实测值）；`#807878` 仅用于非文字几何。
- 语义地标：`header` / `main` / `footer` / `nav` / `aside`，配方卡 `aria-label`，装饰性 SVG 一律 `aria-hidden="true"`。
- 首屏提供「跳到主要内容」跳转链接，聚焦时可见。
- 所有可交互元素有可见 `:focus-visible` 焦点环（2px `#D4945A`，offset 2px）。
- `prefers-reduced-motion: reduce` 下过渡降到 1ms。
- 触控目标高度 ≥ 40px（按钮 padding 10px + 16px 行高）。
